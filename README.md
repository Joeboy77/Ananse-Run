# Ananse Run

A 3D endless runner rooted in Ashanti folklore, built for the web.

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:5173. Add `?debug=1` for the performance panel. Use `npm run dev:phone` to test on a phone on the same Wi-Fi.

## Scripts

| Command             | What it does                              |
| ------------------- | ----------------------------------------- |
| `npm run dev`       | Start the dev server                      |
| `npm run dev:phone` | Dev server reachable on the local network |
| `npm run check`     | Type check, lint and unit tests           |
| `npm run build`     | Production build                          |
| `npm run format`    | Format with Prettier                      |
